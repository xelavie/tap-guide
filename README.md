# 수도꼭지 도우미 · Tap Guide

낯선 수도꼭지를 카메라로 찍으면, **찍은 사진 위에** 어디를 어떻게 돌리고 올리고 눌러야 하는지 보여주는 여행자용 모바일 웹앱입니다.
HCI 수업 과제이자 실제 런칭을 목표로 하는 프로젝트입니다.

## 구조 한눈에 보기

- **서버 없음.** 정적 웹앱(React + Vite)이고 GitHub Pages에 배포됩니다.
- **AI는 각자 연결(BYOK).** 앱 안의 `AI 연결` 화면에서 Claude / Gemini / ChatGPT 중 하나를 고르고 **본인 API 키**를 넣으면 됩니다.
  - 키는 그 폰의 브라우저(localStorage)에만 저장됩니다. 개발팀이나 다른 사람은 볼 수 없습니다.
  - 사진은 앱 서버를 거치지 않고 고른 AI 회사로 바로 전송됩니다.
  - API 요금은 각자 계정에 청구됩니다.
- AI가 없어도 **샘플 사진 체험**과 **비슷한 모양 직접 고르기**는 그대로 동작합니다.

## 팀원용: 폰에서 써보기

1. 배포 주소를 폰 브라우저(iPhone은 Safari, Android는 Chrome)로 엽니다.
2. 공유 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
3. 카메라 화면 오른쪽 위 **`AI 연결`** 버튼을 누릅니다.
4. AI 서비스를 고르고, `키 발급 페이지 열기`에서 키를 만든 뒤 붙여넣습니다.
5. **연결 테스트**에서 초록색 `✓ 연결됐어요`가 뜨면 끝입니다.

| AI | 키 발급 | 기본 모델 |
|---|---|---|
| Gemini (Google) | https://aistudio.google.com/apikey | `gemini-3.6-flash` |
| Claude (Anthropic) | https://console.anthropic.com/settings/keys | `claude-sonnet-5-5` |
| ChatGPT (OpenAI) | https://platform.openai.com/api-keys | `gpt-5.5` |

모델 이름은 설정 화면에서 바꿀 수 있습니다(더 싸거나 빠른 모델로 비교 테스트할 때 유용).

## 인식 흐름

```
촬영/앨범 → 사진 축소(최대 1280px) → 내 AI에 전송
   → AI가 { 유형, 신뢰도, 부품 위치(x,y %), 메모 } JSON 반환
   → 신뢰도 ≥ 0.6 이고 아는 유형이면: 내 사진 위에 핀·화살표 표시
   → 아니면: "잘 모르겠어요" 화면 + 비슷한 모양 직접 고르기
```

- AI가 찾은 부품만 핀으로 표시되고, 각 단계의 동작 화살표는 해당 부품 위치를 따라갑니다.
- 결과 화면 오른쪽 아래 `예시 사진`을 누르면 기준 예시 사진과 비교할 수 있습니다.
- AI가 특이사항을 발견하면(예: 온수/냉수 표시가 반대) `AI 메모`로 보여줍니다.
- 테스트 중 확인용으로, `AI 연결` 화면 맨 아래 **최근 인식 기록**에서 AI 원본 응답·소요 시간을 볼 수 있습니다.

## 지원 유형 (현재 5종)

| id | 이름 |
|---|---|
| `lever` | 싱글레버 혼합수전 |
| `two` | 좌우 2핸들 수전 |
| `sensor` | 센서식 자동수전 |
| `thermo` | 온도조절 써모스탯 |
| `diverter` | 샤워 전환 밸브 (3핸들) |

유형을 추가하려면 `src/data/faucets.js`(가이드 내용)와 `src/ai/recognize.js`의 `CATALOG`(AI가 보는 설명)에 같은 id로 추가합니다.

## 개발

```bash
npm install
npm run dev      # 같은 와이파이의 폰에서 http://<내 IP>:5173 접속 (카메라는 HTTPS에서만 동작)
npm run build    # dist/ 생성
```

`main` 브랜치에 push하면 GitHub Actions가 자동으로 빌드해서 GitHub Pages에 배포합니다
(저장소 Settings → Pages → Source를 **GitHub Actions**로 한 번 설정해야 합니다).

### 파일

| 경로 | 역할 |
|---|---|
| `src/App.jsx` | 화면(온보딩·촬영·분석·실패·결과·공유)과 화면 전환 |
| `src/Settings.jsx` | AI 연결 설정 화면 |
| `src/overlay.jsx` | 사진 위 핀/화살표 오버레이, 공유용 이미지 생성 |
| `src/ai/providers.js` | Claude / Gemini / OpenAI 직접 호출 |
| `src/ai/recognize.js` | 프롬프트, 사진 전처리, AI 결과 → 내 사진 위 가이드 변환 |
| `src/ai/config.js` | 키·모델 설정 저장(브라우저 로컬) |
| `src/data/faucets.js` | 유형별 핀·단계·안전 문구 |
| `src/data/i18n.js` | 한/영 문구 |

## 알려진 한계 / 다음 할 일

- 샘플 이미지 5장은 쇼핑몰 제품 사진(임시)입니다. 공개 런칭 전 직접 찍은 사진이나 일러스트로 교체해야 합니다.
- `링크 복사`는 유형의 예시 가이드로 연결됩니다(내 사진은 서버가 없어서 링크로 공유되지 않음). 내 사진 가이드는 `이미지 저장`/`다른 앱으로 보내기`로 공유하세요.
- 유형 확장 후보: 욕조 토수구 당김식 전환, 영국식 온·냉수 분리 수도꼭지, 누름 버튼(타이머)식, 돌리기만 하는 1핸들 샤워 밸브, 전기샤워기.
- "도움이 됐나요?" 피드백 수집(문구만 준비됨).
